# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/ryotan/suzunari-error/security/advisories/new), not in a public issue.

This is a personal project with a single maintainer, so there is no guaranteed response time. Once a fix is released, the advisory is disclosed publicly.

## Supported versions

Only the latest release receives security fixes.
